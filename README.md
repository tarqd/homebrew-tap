# Tarqd Tap

## How do I install these formulae?

`brew install tarqd/tap/<formula>`

Or `brew tap tarqd/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tarqd/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
